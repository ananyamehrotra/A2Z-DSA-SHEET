# A2Z-DSA-SHEET

A comprehensive Data Structures and Algorithms practice repository organized by topics.

This repository is organized into the following topic-wise folders:

- [01-Learn-the-basics](./01-Learn-the-basics/) - Fundamental programming concepts and basic data structures
- [02-Learn-Important-Sorting-Techniques](./02-Learn-Important-Sorting-Techniques/) - Various sorting algorithms and implementations

### 🔍 Arrays and Searching
- [03-Solve-Problems-on-Arrays](./03-Solve-Problems-on-Arrays/) - Array manipulation problems and solutions
- [04-Binary-Search](./04-Binary-Search/) - Binary search problems and applications

### 💻 Data Structures

- [09-Stack-and-Queues](./09-Stack-and-Queues/) - Stack and queue data structure problems
- [11-Heaps](./11-Heaps/) - Heap data structure problems and applications

### 🎯 Problem-Solving Techniques
- [07-Recursion](./07-Recursion/) - Recursive algorithms and problems
- [08-Bit-Manipulation](./08-Bit-Manipulation/) - Bit manipulation problems and techniques
- [10-Sliding-Window-Two-Pointer](./10-Sliding-Window-Two-Pointer/) - Sliding window and two pointer technique problems
- [12-Greedy-Algorithms](./12-Greedy-Algorithms/) - Greedy algorithm problems and techniques
- [16-Dynamic-Programming](./16-Dynamic-Programming/) - Dynamic programming problems and techniques

### 🌳 Tree Structures
- [13-Binary-Trees](./13-Binary-Trees/) - Binary tree problems and algorithms
- [14-Binary-Search-Trees](./14-Binary-Search-Trees/) - Binary search tree problems and operations
- [17-Trees](./17-Trees/) - General tree problems and algorithms

### 🔗 Graph Theory
- [15-Graphs](./15-Graphs/) - Graph algorithms and problems

- Implementation examples in various programming languages
